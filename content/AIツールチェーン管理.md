## hermesの活用状況

### スケジュールジョブ

| 種類 | 用途 |
|------|------|
| 定時メンテ・バックアップ | サーバーの保守やデータバックアップ |
| データ取得・分析 | 定期的にデータを取得・処理 |
| 通知・レポート | 定期レポートやアラート通知 |
| 開発ワークフロー | CI/CDやデプロイの自動化 |

### 実装スキル

- データ収集（Webスクレイピング、API取得）
- 通知系（定期的なメールやSlack通知）
- サービス連携（外部サービスの自動操作）

> [!note] セルフホスト理由
> hermesはセルフホストのみ対応。クラウド版は存在しない。

## 課題と改善案

### 現状の問題点

| 項目 | 状態 | リスク |
|------|------|--------|
| 情報管理 | 未管理 | **高** - 後から追跡困難 |
| ツール間連携 | なし | **中** - 手動の手間 |
| 無料枠 | 気にしていない | **低** |

### 改善提案

#### 1. Obsidian導入（情報基盤）
- ローカルノートアプリ
- Markdownで管理
- ツール間リンクで関係性を可視化
- グラフ表示で全体像が見える

#### 2. n8n導入（自動化基盤）
- make/zapierのセルフホスト版
- 400+の統合
- hermesと連携しやすい

#### 3. 定期レビュー体制
- 月1でツールの見直し
- 無料枠の使用量確認
- ツール追加/削除の検討

## AI利用ポリシー

### データ分類基準

| 分類 | 定義 | AI入力可否 | 具体例 |
|------|------|------------|--------|
| **公開情報** | 一般公開済み | ◎ 可 | 公開ページ、プレスリリース |
| **社内限定** | 社外秘だが個人と非紐付き | △ 条件付き可（匿名化） | 業務マニュアル、議事録要約 |
| **社外秘** | 漏れると不利益 | × 原則禁止 | 未公開事業計画、見積根拠 |
| **極秘・個人情報** | 個人特定可能、最重要機密 | × 禁止 | 顧客PII、財務詳細、M&A情報 |

> [!tip] 判断基準
> 判断に迷う場合は、より厳しい分類として扱う。

### 学習ありモデルの使い分け

| 利用形態 | データの学習利用 | 実務上の注意 |
|----------|------------------|--------------|
| 無料プラン（Web UI） | **初期設定で学習に使われる** | 設定で無効化しても個人アカウントは管理不可 |
| 法人向け（Team/Enterprise） | **学習に使われない** | 管理者が組織全体の設定を統制可 |
| API経由 | **学習に使われない** | キー管理・利用ログの一元化が前提 |

> [!important] 原則
> 業務利用は法人契約またはAPIに限定し、個人アカウントでの業務利用を禁止。

### SaaS利用時のチェックポイント

| チェック項目 | 確認内容 |
|--------------|----------|
| **学習利用の有無** | 顧客データがモデル学習に使われるか |
| **データ保持期間** | プロンプト・応答がどこに保存されるか |
| **管理者ログ機能** | 誰が・いつ・何を入力したか追跡可能か |
| **越境移転** | データがどこで処理されるか |
| **再委託** | AIプロバイダ以外にデータが渡るか |

### 入力禁止情報リスト

```
【入力禁止情報】
- 顧客・従業員の個人情報（氏名、連絡先、識別可能な情報）
- 未公開の財務情報・事業計画・見積根拠
- 秘密保持契約に基づき受領した取引先の情報
- 他者の著作物（記事、有料コンテンツ、他社コード等）
- 認証情報（パスワード、APIキー等）
- 自社ソースコード（許可されたコード補助ツールを除く）
```

### 技術的統制

| 統制 | 効果 |
|------|------|
| **DLP** | 機密パターンの送信を検知・ブロック |
| **法人契約・API標準化** | 学習利用をオプトアウト設定 |
| **SSO・アクセス制御** | 未承認サービスへのアクセス制限 |
| **監査ログ** | 利用記録の保存（最低1年） |
| **APIキー管理** | ソースへのハードコード禁止、定期ローテーション |

### ツール別リスク評価

| ツール | リスクレベル | 推奨対応 |
|--------|--------------|----------|
| sakana/deepseek/qwen（無料） | **高** | 公開情報のみ入力 |
| opencode（公開リポジトリのみ） | **低** | 制約が正しい |
| hermes（セルフホスト） | **低** | 自社環境で完結 |
| make/zapier/bolt.ai | **中** | DPA確認必須 |
